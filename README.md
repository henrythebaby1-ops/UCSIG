# Using Coding Skills In Games

A browser game that teaches JavaScript, Python, HTML, CSS, C, C++ and Java. Every level is solved by writing real code: print answers to the console, build platforms with function calls and loops, change gravity with a variable, fix buggy code, and style the level with CSS.

Play it: https://henrythebaby1-ops.github.io/using-coding-skills-in-games/
