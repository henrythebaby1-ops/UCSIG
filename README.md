# Using Coding Skills In Games

A browser game that teaches JavaScript, TypeScript, Python, HTML, CSS, C, C++ and Java across 37 levels. Byte, a robot tutor, teaches each idea and gives you a practice exercise first. Then you solve the level by writing real code in a CodeMirror editor: print answers to the console, build platforms with function calls and loops, change gravity with a variable, fix buggy code, and style the level with CSS.

Play it: https://henrythebaby1-ops.github.io/UCSIG/
